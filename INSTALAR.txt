LINUXAVENTURA 0.3 — 10 JUEGOS Y UN EXTRA

1. Descomprime el paquete.
2. Sube el CONTENIDO de la carpeta linuxaventura a la raíz de jmalvido/linuxaventura.
   Sustituye los archivos coincidentes. No subas datos/ de ninguna máquina.
3. En la VM, cierra el juego y ejecuta:

sudo apt update
sudo apt install python3 wget ncal man-db info
bash ~/actualizar_linuxaventura.sh

Si todavía no tienes el script:

cd ~
wget -O actualizar_linuxaventura.sh https://raw.githubusercontent.com/jmalvido/linuxaventura/main/actualizar_linuxaventura.sh
bash ~/actualizar_linuxaventura.sh

4. Para jugar:

bash ~/linuxaventura/jugar.sh

ACTUALIZAR dentro del juego solo descarga actividades: esta versión necesita también
los cambios del motor, de retos.py, menú y terminal. Usa el script completo.
El progreso y los escenarios existentes se conservan. Las actividades 1–4 no cambian.
Los alias y el historial se guardan por actividad. REINICIAR limpia los de esa actividad.

Para probar antes de subirlo, copia el contenido de linuxaventura sobre tu instalación
con el juego cerrado y sin borrar la carpeta datos. Instala también las dependencias.

El extra aparece como opción 11. El último juego de la unidad es el 10: 12 etapas.
Las soluciones y el mapa de contenidos están en docs/GUIA_PROFESOR.md.
El README mantiene el orden acordado: qué es, descarga/juego e instrucciones.

Verificación: 15 pruebas automáticas superadas, incluidas dos con Bash interactivo real.
El calendario del expediente se simula en el test porque el entorno de desarrollo no
tiene cal. Revisa calendario y manuales en Ubuntu durante el piloto del aula.
